# 中国并购交易结构方案规划 Skill

`handling-china-ma-transactions` 把交易目标和项目事实转成可比较的结构路径：推荐基准方案，设置备选与兜底，并把需要后续专业团队完成的工作整理成标准任务包。

技术调用名和目录保持不变；默认 `Buyer`，可切换为 `Seller`。

## 产品承诺

固定工作流：

`六组输入 → 三维分析 → 八部分输出 → 双版本方案 + 四类任务包`

本 Skill 只负责交易结构方案规划。它不会因发现一个问题就扩展成完整交易执行项目。

## 快速上手

1. 在任务中明确调用 `$handling-china-ma-transactions`。
2. 提供现有材料并填写[事项入项表](skills/handling-china-ma-transactions/assets/matter-intake-template.md)。
3. 指定买方或卖方立场、目标决策人和基准日期。
4. Skill 比较基准、备选、兜底方案，并输出管理层决策版、律师执行版和四类任务包。

最小调用示例：

```text
使用 $handling-china-ma-transactions，从 Buyer 立场规划以下中国并购交易。
请先按固定六组输入识别缺口，再围绕控制权、收购方式、合并财务报表三维比较基准、备选、兜底路径，输出八部分方案、管理层决策版、律师执行版，以及尽调、交易文件、审批、会计四类任务包。
```

## 六组固定输入

| 序号 | 输入组 | 内容 |
|---|---|---|
| 1 | 事项信息 | 阶段、立场、法域、基准时点、保密、决策人 |
| 2 | 商业目标 | 收购目的、目标权力、并表、预算、期限、不可牺牲目标 |
| 3 | 交易事实 | 股权/权益、表决权、治理、标的、对方和控制链 |
| 4 | 可选路径 | 股权/股份、增资/发行、资产/业务、分步、间接及已有设想 |
| 5 | 硬约束 | 比例、审批、standstill、资金、时间、税务、国资、外资、数据等 |
| 6 | 材料与缺口 | 文件版本、未确认事实、冲突、责任人和关闭证据 |

每个字段同时记录要求等级和事实状态：

- 要求等级：`start-required`、`assumption-allowed`、`recommendation-blocker`；
- 事实状态：`confirmed`、`assumed`、`missing`、`conflicting`、`external-confirmation-pending`。

启动字段缺失时不启动；阻断推荐字段未关闭时可以比较路径，但状态为 `blocked`，不作确定推荐。

## 三维分析

| 维度 | 核心问题 | 输出 |
|---|---|---|
| 控制权 | 交易后需要取得什么权力，从何时取得 | 控制口径、支持事实、反证、取得时点 |
| 收购方式 | 哪种工具、组合和顺序最能实现目标 | 基准、备选、兜底，或排除原因 |
| 合并财务报表 | 路径事实能否支持控制和购买日判断 | 支持与反证、缺失证据、会计师确认包 |

三条稳定路由：

- `L-CONTROL`：上市公司控制或潜在控制权收购；
- `P-EQUITY`：非上市公司股权收购、控制型增资和分步交易；
- `P-ASSET`：资产、业务和 carve-out 收购。

## 八部分固定输出

1. 项目状态及分析边界；
2. 一页式方案结论；
3. 三维目标及当前状态；
4. 基准、备选、兜底三个方案比较；
5. 推荐方案、推荐理由及成立条件；
6. 关键反证、缺失事实和待决策事项；
7. 签署—审批—交割—控制取得—并表判断时间线；
8. 后续任务包。

使用[三维结构方案模板](skills/handling-china-ma-transactions/assets/three-axis-structure-template.md)可以直接落表。

## 双版本

- 管理层决策版：突出一页式结论、商业差异、成立条件、主要反证、时间/预算影响和待决策事项。
- 律师执行版：保留完整八部分、事实和版本、法源核验、缺口闭环与任务包。

两版来自同一底层分析；方案编号、关键事实、状态、推荐结论和时间线必须一致。

## 四个后续接口

使用[后续任务包模板](skills/handling-china-ma-transactions/assets/downstream-task-packages-template.md)：

| 接口 | 本 Skill 输出 | 后续团队负责 |
|---|---|---|
| 尽调任务包 | 验证结构路径所需的事实、材料和关闭证据 | 执行专项核查并回传结果 |
| 交易文件任务包 | 步骤联动、CP、long-stop、失败恢复、控制切换及验收条件 | 起草、审阅和谈判交易文件 |
| 审批任务包 | 影响路径和时点的审批、同意、登记、报告及 standstill | 专项判断、申报和监管沟通 |
| 会计任务包 | 控制、并表和购买日的支持事实、反证及问题 | 管理层和会计师作出会计判断 |

## 使用边界

本 Skill 不完成：

- 全面法律尽调；
- 整套交易文件起草或审阅、SPA/APA 红线或全议题谈判；
- 审批申报、监管沟通、交割管理；
- 会计、税务、估值、环境、技术或行业专项结论；
- 交割后整合或索赔管理。

上述事项只在直接影响结构时进入后续任务包。外国法由当地合资格律师确认；当前版本不搜索、引用或计算外国申报阈值。

## 示例

上市公司控制权：

```text
我方拟协议受让 A 股公司 29% 股份并取得董事会多数，希望控制并并表。请按六组输入标记缺口，比较协议转让、发行组合及兜底路径，给出控制取得与购买日时间线，并输出双版本方案和四任务包。
```

非上市公司分步收购：

```text
我方先收购境内目标 40%，满足行业许可后再增持至 70%。请比较分步、一次性交割和资产路径，重点说明第二步失败后的剩余权利、long-stop、治理降级和改道条件。
```

资产与业务收购：

```text
我方拟收购生产线、人员、合同和许可，但核心系统需卖方提供一年 TSA。请比较逐项资产、先剥离 NewCo 再收股和直接收股三条路径，并形成业务连续性与会计分类任务包。
```
