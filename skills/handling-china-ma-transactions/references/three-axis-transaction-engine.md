# 三维交易结构方案引擎

本引擎把固定输入转成可比较路径、并表证据和后续任务包。它只做规划，不执行尽调、文件审阅、申报、会计判断或交割管理。

## 固定分析序列

1. 建立事项边界：记录立场、路由、法域、基准时点、保密等级和完成状态。
2. 校验六组输入：区分不能启动、可假设推进和阻断确定推荐的缺口。
3. 标记三维目标：控制权、收购方式、合并财务报表分别使用 `required`、`not-sought`、`not-applicable`、`pending-professional-confirmation` 或 `blocked`。
4. 先确定控制权目标：列出各控制口径的支持事实、反证、目标权力和取得时点。
5. 围绕控制目标生成和比较路径：形成基准、备选、兜底三条路径；不足三条时逐项列明被排除路径及原因。
6. 从前两维提取并表证据：对每条路径记录权力、回报、反证、购买日候选和外部确认事项。
7. 选择推荐：列明推荐理由、成立条件、改道触发器和管理层决策请求。
8. 从同一分析派生八部分输出、管理层决策版、律师执行版和四类后续任务包。

前一步的结论是后一步的输入；不得独立罗列路径或倒推一个想要的并表结论。

## 第一维：控制目标

回答“交易后需要能够决定什么、从何时开始决定”。分别记录证券监管控制、公司治理控制、经营者集中控制、会计控制和外资/安全审查控制，不得相互替代。

每种口径至少记录：当前事实、目标事实、支持控制、反证或保护性权利、取得时点、缺失证据和确认人。持股比例、拥有权益、可支配表决权、特定会议票数、全面摊薄比例和会计权力分别计算；单一比例、董事提名权或协议标题不能直接推出控制。

`P-ASSET` 将第一维适配为资产边界和经营主导权，识别买方何时能够主导生产、采购、定价、客户履约、预算、人员和资本开支，不虚构对卖方主体的公司治理控制。

## 第二维：路径比较

方案编号固定为：

- A：基准方案，最直接满足目标的路径；
- B：备选方案，在主要约束触发时仍可能满足目标；
- C：兜底方案，在 A、B 失败时保护最低商业目标或有序退出。

每条路径统一比较：

| 比较项 | 必须回答 |
|---|---|
| 权力结果 | 持股、权益、表决权、治理、经营主导权及取得时点 |
| 步骤与依赖 | 股权/股份、增资/发行、资产/业务、分步或间接工具；步骤是否一揽子或可拆分 |
| 约束 | 审批、同意、登记、披露、standstill、资金、时间、税务及专业接口 |
| 经济与执行 | 对价、融资、成本、期限、执行确定性和竞态风险 |
| 会计证据 | 支持事实、反证、购买日候选及会计师确认缺口 |
| 失败与改道 | 单步失败后剩余权利、恢复原状可行性、替代路径和退出窗口 |

### 步骤联动与失败恢复

组合交易必须分别标记签署、合同效力、监管决定、交割、过户/交付、治理切换、控制取得和购买日。需要商业联动时，规划层优先比较有限 CP、同步或交叉交割、long-stop、交叉终止、价格调整、替代交易和恢复原状安排，不把所有商业条件机械转为生效条件。

每个步骤写明：前置依赖、是否可豁免、责任方、完成证据、最迟时间、失败后果及下一路径。法定审批或 standstill 不得约定豁免，也不得用保证或赔偿替代。

控制切换必须与付款和权利转移分开。董事当选、管理层任免、印章/账户/系统权限、资产交付及实际经营移交各自记录生效时点；过渡期价值保护不得构成提前实施控制。

## 第三维：并表证据检验

从每条路径提取：

- 交易前后持股、表决权和全面摊薄表；
- 相关活动及其决策机制；
- 董事与关键管理层的提名、实际当选、罢免和任免；
- 预算、商业计划、融资、重大交易、分红和资产处置权限；
- 其他股东实质性或保护性权利、潜在表决权和代理关系；
- 过渡期与 standstill 对买方行权的限制；
- 可变回报以及买方运用权力影响回报的能力；
- 候选购买日及每一候选日的完成证据。

输出“支持事实—反证—缺失证据—购买日候选—会计任务包”，不输出会计结论。硬性并表目标缺少专业确认时标记 `pending-professional-confirmation`；结构事实明显不支持且不能合理改造时标记 `blocked`，并改道或排除该方案。

`P-ASSET` 另检验取得组合是否包含投入与实质性加工处理过程、集中度测试是否适用，以及确认日 / 购买日证据；分类由管理层和项目会计师判断。

## 推荐规则

推荐必须来自三条路径的同字段比较，并写清：

1. 满足哪些控制与商业目标；
2. 依赖哪些 `confirmed` 事实；
3. 哪些非 confirmed 项不会改变推荐，哪些会触发改道；
4. 何时转向 B 或 C，何时升级为退出决策；
5. 需要管理层作出的具体决定。

存在未关闭的 `recommendation-blocker` 时，仍可给条件式排序，但不得写确定推荐。

## 四类任务包

只把直接影响结构选择或成立条件的事项送入任务包：

- 尽调任务包：核实结构路径所需事实，不生成全面尽调清单；
- 交易文件任务包：移交步骤联动、CP、long-stop、失败恢复、控制切换和证据要求，不起草或审阅整套文件；
- 审批任务包：移交影响路径或时点的审批、同意、登记、报告与 standstill，不执行申报；
- 会计任务包：移交控制、并表和购买日事实，不给会计结论。

所有结果必须按统一回传字段更新输入状态、控制矩阵、路径可行性、时间线和推荐状态。
