# 三维交易决策内核

本模块是中国投资并购决策与执行 Skill 的产品内核。先确定控制权目标，再比较收购方式，最后验证合并财务报表目标；尽调、审批、条款、谈判和交割均服务于这三维，而不是独立堆砌问题。

## 1. 先给三维定状态

入项时分别记录：

- `required`：本交易必须实现；
- `not-sought`：交易明确不追求该结果；
- `not-applicable`：该维与交易对象或路径无关；
- `pending-professional-confirmation`：已识别目标和事实，但需审计师、税务师、估值师或其他专业人士确认；
- `blocked`：关键事实或法定条件不足，不能可靠设计。

不得静默跳过任何一维。状态不是结论；`required` 仍需写出支持事实、反证和完成证据。

## 2. 起点：控制权

先回答“交易完成后，买方需要能够决定什么、从何时开始决定”。分别分析：

| 控制口径 | 核心问题 | 主要事实 | 最终确认 |
|---|---|---|---|
| 证券监管控制 | 是否构成上市公司控制、权益如何合并计算 | 持股、拥有权益、一致行动、表决权、董事选任、股东会影响 | 证券律师及当期正式规则 |
| 公司治理控制 | 谁能实际决定股东会、董事会和关键管理层 | 章程、协议、董事实际当选、保留事项、任免和历史运行 | 公司治理文件及交割事实 |
| 经营者集中控制 | 是否取得控制或决定性影响、何时实施集中 | 权利结构、否决权、治理、商业依赖、分步交易 | 反垄断专项分析 |
| 会计控制 | 是否具备权力、可变回报和影响回报能力 | 相关活动、实质性权利、回报、代理关系、反证 | 管理层和项目审计师 |
| 外资/安全审查控制 | 特定制度下是否取得实际控制 | 主体、行业、治理、技术/数据和实际影响 | 对应主管规则及专项顾问 |

分别记录持股比例、收购规则下拥有权益、可支配表决权、特定会议票数、全面摊薄比例和会计权力。每项列明：当前事实、交割后事实、支持控制、反证/保护性权利、取得时点、缺失证据和负责人。

不得从单一比例、董事提名权、协议标题或“不可撤销”字样直接推导控制。

## 3. 重点：收购方式

围绕控制目标生成和比较路径。结构设计请求在事实允许时至少比较三个方案：基准方案、主要替代方案和失败 fallback；如果只剩一个可行方案，列明其他路径的排除原因。

方案可以包括股权/股份转让、增资、向特定对象发行、要约、二级市场取得、间接收购、资产/业务收购、法定合并、表决权安排、董事会安排和分步组合。每个方案统一比较：

1. 目标持股、拥有权益、表决权、治理和控制取得结果；
2. 要约、发行、过户、登记、许可和信息披露路径；
3. 签署前授权、合同效力、交割前审批、standstill 和交割后义务；
4. 价格、融资、资金、税务、估值和会计接口；
5. 签署、生效、监管决定、付款、过户/交付、治理切换和购买日；
6. 执行确定性、时间、成本、互相依赖和竞态风险；
7. 单项失败后果、恢复原状可行性、替代交易、long-stop 和退出；
8. 对第三维的支持事实与反证。

组合交易必须区分合同成立、合同效力与交割联动。需要整体商业联动时，优先通过有限交割条件、long-stop、交叉终止、价格调整和替代路径处理，不把所有商业条件机械写成合同生效条件。

## 4. 靶点：合并财务报表

先把该维标记为 `required`、`not-sought`、`not-applicable` 或 `pending-professional-confirmation`。并表为硬目标时，从前两维提取：

- 交易完成前后的持股、表决权和全面摊薄表；
- 相关活动及其决策机制；
- 董事和关键管理层的提名、实际当选、罢免和任免；
- 预算、商业计划、融资、重大交易、分红和资产处置权限；
- 其他股东的实质性或保护性权利；
- 表决权安排、潜在表决权、代理关系和历史表决事实；
- 过渡期、standstill 和其他限制买方行权的条件；
- 可变回报及买方运用权力影响回报的能力；
- 候选购买日及每一候选日的完成证据。

输出“支持事实—反证—缺失证据—购买日候选—审计师确认包”，不得承诺“可以并表”。条件式结论使用：

> 在【支持事实】实际成就、不存在【反证】且经管理层与项目审计师按交割时事实确认的前提下，该结构可支持控制和并表评估。

## 5. 路由适配

| 路由 | 第二维度的最低处理 |
|---|---|
| `L-CONTROL` | 完整执行三维；控制口径、30%要约路径、发行/过户、治理改组、过渡期和并表证据均不得省略 |
| `P-EQUITY` | 处理现有股权收购、控制型增资、分步收购及与并购实质相连的少数股权安排；区分少数保护、共同控制和单独控制；不追求控制或并表时显式写 `not-sought` |
| `P-ASSET` | 第一维改为收购边界及业务/资产经营主导权；第二维比较资产、业务、股权和 carve-out；第三维识别资产收购、业务合并、会计范围和购买日并交专业人士确认 |

纯新增少数股权融资且不以取得控制、业务或资产为目的时，先记录控制权与并表均为 `not-sought`，说明该事项超出本 Skill 的实质并购边界，再转交 PE/VC 融资文件审阅能力；不得继续以 `P-EQUITY` 全面审阅融资条款。若少数股权交易是现有股权收购、分步取得控制的前置步骤，或与业务/资产收购不可分，则保留在 `P-EQUITY`，并写明并购实质。

纯法条查询无需虚构完整结构，但应说明该规则通常影响哪一维。非结构类交付物只展开相关部分，同时标注其 `影响维度`。

## 6. 执行支持层

三维决定完成后，把每个重大问题落到一个或多个交易工具：

| 执行层 | 必须回答 |
|---|---|
| 尽调 | 需要验证哪一维、缺什么材料、什么证据可以关闭 |
| 审批 | 影响哪一方案或控制时点，属于签署前、效力、交割前、交割后还是持续义务 |
| 条款 | 应进入价格、CP、交付物、保证、披露、赔偿、承诺、终止、担保还是交割后行动 |
| 谈判 | 首选、give/get、fallback 和 walk-away 如何保护三维硬目标 |
| 交割 | 付款、过户/交付、治理切换、控制取得和购买日分别需要什么证据 |

使用 [three-axis-structure-template.md](../assets/three-axis-structure-template.md) 输出结构建议。每项行动保留负责人、截止日、完成证据和状态。

## 7. 来源与边界

- 现行法律结论使用当前官方硬法源；
- 监管问询和案例只证明个案事实或风险信号；
- 文章及泰胜风能材料用于生成结构问题和失败模式，不作为现行规则；
- 法律控制、经营者集中控制和会计控制不得相互替代；
- 审计、税务、估值、行业技术和外国法最终判断由相应专业人士完成。
