# 审批约束与任务包接口

本模块只识别会改变结构路径、控制取得时点或推荐成立条件的审批、申报、备案、登记、报告、第三方同意和 standstill。它形成审批任务包，不执行申报、监管沟通或交割管理。

## 使用规则

1. 先从六组输入提取主体、控制链、行业、地域、交易金额/营业额、资金路径、国资/外资属性、数据与技术及分步关系。
2. 只加载被事实触发的专题，不返回全量审批清单。
3. 每一约束必须关联方案 ID、影响维度、触发事实和法源核验状态。
4. 将时点分为签署前、合同效力、交割前、交割后或持续阶段。
5. 法定审批与 standstill 不得约定豁免，也不得由保证、赔偿或免责声明替代。

## 路径约束地图

| 专题 | 结构规划问题 | 典型结果回传 |
|---|---|---|
| 经营者集中 | 是否取得控制/决定性影响、分步是否一揽子、何时不得实施 | 申报判断、standstill、允许交割时点、补救对路径的影响 |
| 上市收购/发行 | 取得路径、权益合并、要约、审核注册、过户和披露时点 | 可行路径、比例/时点限制、审核或要约失败后果 |
| 国资 | 主体层级、评估、定价、进场、批准/备案/报告及付款要求 | 必经步骤、责任主体、阶段、完成证据 |
| 外资准入/安全审查 | 投资者、行业、实际控制和敏感要素 | 准入限制、审查前置、路径改造或排除原因 |
| ODI/外汇 | 境内买方、资金来源、路径与对外支付 | 中国侧前置、资金可得性、long-stop 输入 |
| 数据/技术出口/出口管制 | 数据、技术、物项、跨境访问或转移安排 | 可转移边界、条件、隔离或替代路径 |
| 行业许可/劳动/IP/税务 | 许可是否随主体、人员/权利转移和税负差异 | 结构可行性、专项确认和路径成本 |

具体触发、阈值、动作动词和机关名称必须使用当期官方法源核验。境外法只列触发因素和当地律师任务；不得检索、引用或计算外国申报阈值。

## 审批任务包字段

统一使用：`Package ID｜接收方｜来源方案/维度｜目的｜待核事实/待完成动作｜输入材料｜问题或指令｜责任人｜期限/阶段｜完成证据｜结果回传字段｜状态`。

结果回传至少更新：

- 方案可行、需改造或排除；
- 签署、效力、交割、控制取得和并表判断时间线；
- CP、long-stop、交叉终止、补救承诺权限和失败恢复要求；
- 对基准、备选、兜底排序及完成状态的影响。

## 边界

审批任务包不等于申报意见或申报执行。最终判断、文件准备、递交、监管沟通和补救谈判由对应专项律师或顾问完成；本模块只接收结果并回填结构方案。
