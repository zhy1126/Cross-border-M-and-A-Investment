# A股上市公司控制权收购（`L-CONTROL`）

## 使用方法

先读取入项和法源协议，再用法规脚本按交易所、板块、取得路径和交易日期复核。本文是问题地图，不替代当期《证券法》《上市公司收购管理办法》、发行注册规则及交易所业务规则。

## 三维内核接口

本路由完整执行控制权—收购方式—合并财务报表三维内核，并使用 `assets/three-axis-structure-template.md` 汇总：

1. **控制权输入/输出**：输入买方目标、现有持股、各方关系、股权分散度、表决和董事会事实；输出五种控制口径、六套比例、支持事实、反证和取得时点。
2. **收购方式输入/输出**：输入可转股份、发行可行性、资金、时间、审批及失败容忍度；输出至少三个结构方案或排除原因，并比较协议转让、要约、发行、表决权、董事会及分步组合。
3. **并表接口**：把相关活动、实际当选董事、保留事项、关键管理层、治理切换和过渡期限制交给会计模块；只输出并表支持度和证据包，不承诺结果。

尽调、审批、文件和谈判问题必须标注其影响维度。例如，股份质押首先影响收购方式和交割；原股东预算否决权同时影响控制权及并表；发行注册失败影响第二步路径但不当然使第一步失效。

## 1. 先拆开五种“控制”

| 口径 | 核心问题 | 不得替代的确认 |
|---|---|---|
| 收购监管 | 是否满足收购办法的控制标准、权益/一致行动如何合并计算 | 证券律师、当期正式规则 |
| 公司治理 | 谁能实际决定股东会、董事会和关键管理层 | 章程、协议、任免事实 |
| 经营者集中 | 是否取得控制或决定性影响，何时可能实施集中 | 反垄断专项分析 |
| 会计 | 是否同时有权力、可变回报及运用权力影响回报 | 项目审计师/会计判断 |
| 外资/安全审查 | 特定规则下是否取得实际控制 | 对应主管规则/顾问 |

输出不得说“29%+董事提名权当然取得控制并可以并表”。应写为“结构旨在支持控制认定/并表”，列出事实条件、反证和确认责任。

2025年修正后收购办法第84条相关表述为“持股超过50%”及“决定董事会超过半数成员选任”。旧官网合并正文或文章中的“50%以上/半数以上”不得直接沿用；签约或公告时把第227号令附件与基础正文逐字合并核对。

## 2. 六套比例口径分别计算

1. 已发行股份持股比例；
2. 收购规则下“拥有权益”的股份（含一致行动和可支配表决权）；
3. 实际可支配表决权；
4. 特定股东会出席并参与表决票数；
5. 发行/回购/表决权放弃后的全面摊薄比例；
6. 会计控制中的现时主导能力。

表决权放弃是否改变某一分母、提名独立董事是否构成“决定选任”、合同声明“不构成一致行动”是否有效，都必须按实质和具体口径判断。

## 3. 权益变动与一致行动

- 绘制直接/间接持股、共同投资、亲属、融资、协议、历史协同行为和受托表决权地图；
- 检查首次达到披露线、后续整数倍/每档变动、被动稀释/增加及暂停交易要求；
- 一致行动是实质判断，不能仅凭反向声明排除；
- 同时跟踪收购人资格、资金来源、财务顾问、持续督导和收购后锁定；
- 任何具体百分比、天数和报告类型都从当期官方法源检索并写核验日。

## 4. 30%要约路径不是一个公式

先识别取得路径，再读取对应条款：

- 交易所场内交易；
- 协议收购；
- 间接收购；
- 向特定对象发行及可能的豁免；
- 自愿部分/全面要约；
- 多步骤或一致行动人合计取得。

逐项分析触发时点、部分/全面要约、最低比例、价格、期限、履约保障、预受、按比例收购、豁免、减持恢复和上市地位。超过30%不是当然禁止；低于30%也不等于没有控制、披露或要约问题。

## 5. 结构工具比较

### 协议转让

检查板块规则、最低转让比例/例外、价格边界、交易所确认、中登过户、限售、承诺、质押/冻结、优先权、国资及要约安排。签署、生效、合规确认、付款、过户和控制移交分别画时间点。

### 要约

分析自愿/强制、部分/全面、资金确定性、履约保障、最低价格、预受、竞争要约、公众持股量和终止上市风险。卖方的不接受要约承诺只能按当期规则与可执行性设计。

### 向特定对象发行

按现行注册制规则核验发行对象、发行数量原则、定价、基准日、锁定、战略投资者、审核注册、稀释和要约豁免。旧“非公开发行实施细则”及旧战略投资者问答不得支持当前结论。

### 表决权与董事会安排

分别检验可撤销性、期限、终止、股份处分、受托范围、利益冲突、一致行动、要约、会计和反垄断影响。提名权不等于实际当选，实际当选不当然等于会计控制；独立董事的独立判断不得被写成收购人的指令权。

### 间接收购/分步交易

穿透上层股权、合伙/基金治理、共同控制、融资人权利和两年内分步交易。不得通过形式分步规避披露、要约、反垄断或国资程序。

## 6. “协议转让 + 向特定对象发行”

不要机械复制泰胜风能。至少比较：

1. 两份协议独立成立/生效，交割在有限条件下联动；
2. 先转让后发行，配置发行失败后的持股、控制和价格后果；
3. 先发行后转让，配置审核不确定性和转让方退出；
4. 同日/近同步交割，但不把不必要的商业条件写入发行协议效力；
5. 一项失败时的终止、回购/再转让可行性、替代交易、费用和 long-stop。

每个选项评估：是否形成一揽子交易、是否给发行增加不确定性、要约路径、控制取得时点、经营者集中 standstill、国资/外资、会计购买日和恢复原状的法律可行性。

“互不挂钩”与“必须互为条件”都不是普遍法律结论。历史问询只能作为风险信号。

## 7. 过渡期和抢跑

建立从签约到过户/登记的控制时间线：

- 核验过渡期董事改选限制，来自收购人的董事比例不得突破当期规则；
- 普通经营承诺以价值保护为目的，不得让买方提前经营目标；
- 不得提前派驻管理层、控制账户/印章、批准预算、整合业务或协调竞争行为；
- 竞争敏感信息通过 clean team 汇总；
- 重大资产、担保、分红、融资、关联交易和员工变动设置客观、可执行的同意机制；
- 董事辞任、新董事当选、过户和管理权交接的生效时点分别写明。

基线测试中“交割前选出5名买方董事、过户时任职”的结构仍可能触发过渡期问题，必须专项核验，不能仅靠附条件任职规避。

## 8. 国资与外国投资者

国资不得笼统写“取得国资委批准”。识别中央/地方、收购方/出让方、直接/中间平台、国家出资企业/监管机构授权层级，以及评估、定价、进场、备案/批准/报告和付款规则。

外国投资者另查现行战略投资办法、外资准入、信息报告、安全审查、反垄断、外汇和行业规则；旧2005战略投资办法不得沿用。
