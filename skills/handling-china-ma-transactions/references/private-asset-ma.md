# 资产与业务收购结构规划（`P-ASSET`）

本路由只规划资产包、业务线、经营性资产、门店/产线、知识产权组合和 carve-out 收购结构。它不假设资产交易天然不承债，也不执行逐项转移、文件审阅或交割管理。

## 第一维：P-ASSET 分支：资产边界与经营主导权

列明转入资产、合同、人员、许可、数据、知识产权、存货、应收款、承接与排除负债、共享资源及交割后依赖。检验买方何时能够主导生产、采购、定价、客户履约、预算、人员和资本开支。

最低证据为：权属与负担、合同/许可转移要求、人员与流程迁移、系统与数据权限、Day 1 运营蓝图、TSA 依赖、收益费用切分和控制切换时点。

## 第二维：路径比较

事实允许时至少比较三个方案；不足三个时列明被排除路径及原因。

| 候选路径 | 主要结构约束 |
|---|---|
| 逐项资产购买 | 转移、同意、登记、税务、业务连续性和逐项失败替代 |
| 先剥离至 NewCo 再收股 | 剥离真实性、历史责任、许可/合同迁移和过渡依赖 |
| 直接股权购买 | 主体连续性与历史责任的权衡 |
| 法定合并 | 公司程序、债权人、责任承继、许可和税务专项确认 |

每条路径比较责任隔离、同意数量、资金和税务接口、时间、停摆风险、人员稳定、数据迁移、TSA 退出和失败成本。

## 第三维：P-ASSET 分支：资产收购或业务合并

不以合同标题预设会计分类。向管理层和项目会计师移交以下证据：

- 取得组合中的投入与实质性加工处理过程；
- 有组织员工及知识、经验、系统和流程；
- 产出或持续产出能力；
- 集中度测试的选择与数据（如适用）；
- 同一控制下或非同一控制下的事实；
- 确认日 / 购买日候选及完成证据。

本 Skill 不作资产收购、业务合并、计量或商誉结论。

## 分步转移、依赖与失败恢复

按对象记录转移法律动作、同意/登记、前置条件、交付证据、失败替代和交割后动作。共用合同、许可、系统、场地、品牌或人员不能即时分离时，比较 TSA、许可回授、分阶段迁移、替代供应和延迟交割。

多项转移应规划同步或分批交割、关键资产最低集合、long-stop、价格调整、交叉终止、控制/风险切换和业务连续性兜底；不能用一般保证替代无法转移的核心资产或法定同意。

## 输出与交接

- 尽调任务包：只验证边界、可转移性和业务连续性关键事实；
- 交易文件任务包：只移交资产清单、步骤联动、失败替代、TSA 和控制切换要求；
- 审批任务包：只移交许可、数据、劳动、国资、反垄断及其他路径约束；
- 会计任务包：只移交分类、控制和购买日证据。

本路由不完成全面尽调、APA 起草或审阅、申报、交割、整合或索赔。
