# 会计控制与并表接口

本模块用于识别和组织会计问题，不替代管理层、审计机构或会计专家的专业判断。法律控制、反垄断控制与会计控制须分别分析。

## 0. 前两维输入与第三维输出

从控制权维度和收购方式维度接收以下输入，不完整时把并表状态标记为 `pending-professional-confirmation` 或 `blocked`：

| 前两维输入 | 最低材料 |
|---|---|
| 控制目标和口径 | 证券监管、治理、反垄断和会计控制矩阵 |
| 交易步骤 | 每一步持股、拥有权益、表决权、治理安排和全面摊薄表 |
| 权利生效 | 签署、效力、审批、过户、董事当选、管理层和权限切换时间线 |
| 结构反证 | 其他股东否决权、独立董事、代理关系、过渡期和standstill |
| 失败路径 | 一条交易失败时剩余权利、治理状态和恢复安排 |

本模块返回第三维输出：并表目标状态、控制三要素支持事实、反证、缺失证据、购买日候选、审计师确认包及影响交易条款的行动。将结果回填收购方式比较矩阵；若推荐结构不能支持硬性并表目标，应降级、改造或排除该结构。

并表不是目标时显式标记 `not-sought`；不涉及可合并主体或业务时标记 `not-applicable`，不再展开虚假分析。

## 1. 股权/主体路径：控制三要素

依据当期《企业会计准则第33号》核验：

1. 对被投资方拥有权力；
2. 因参与被投资方相关活动而享有可变回报；
3. 有能力运用权力影响回报金额。

持股或董事席位只是证据，不是完整结论。

## 2. P-ASSET 分支：资产边界与经营主导权

`P-ASSET` 不取得卖方主体股权时，不使用股东会、董事席位或全面摊薄比例推导控制。第一维改为确认买方何时能够独立主导所购资产或业务的生产、采购、定价、客户履约、预算、人员和资本开支，并核对合同、许可、场地、员工、工艺、系统及TSA依赖是否已经实际转移。

经营主导权只说明法律与事实上的移交，不自动决定下述会计分类。

## 3. P-ASSET 分支：资产收购或业务合并

依据当期《企业会计准则第20号——企业合并》及《企业会计准则解释第13号》核验，不以合同标题或“不买股权”预设结果：

1. 识别取得的投入与实质性加工处理过程，及二者是否共同对产出能力有显著贡献；
2. 识别有组织员工是否连同相关知识、经验、系统、标准或流程迁移；
3. 从市场参与者角度判断该组合能否作为业务管理和经营，而非只看买方主观目的；
4. 非同一控制下交易可由企业选择是否采用集中度测试；通过测试指向不构成业务，未通过仍须继续进行业务要素判断；
5. 构成业务后继续区分同一控制下 / 非同一控制下，并识别可辨认资产、负债、或有负债、商誉及计量接口；
6. 不构成业务时，按适用准则识别和计量取得的各项资产与负债，不能照搬业务合并或商誉处理；
7. 分别记录确认日 / 购买日，不机械等于签约、付款、实物交付或某一登记日。

最低证据包：资产/负债边界表、员工及流程迁移表、合同和许可状态、Day 1运营蓝图、TSA、价款分配、集中度测试选择与计算（如适用）、同一控制判断和候选确认日/购买日证据。

法律团队只组织事实和交易响应。会计分类、确认、计量、商誉和报表列示由管理层与项目审计师确认。信息不足时为 `pending-professional-confirmation`；硬性会计目标与结构事实明显冲突、且不能通过改造结构解决时为 `blocked`，不得给出肯定分类结论。

## 4. 股权/主体路径事实清单

- 哪些活动对回报产生重大影响；
- 谁目前有实际能力主导这些相关活动；
- 表决权相对比例、其他股东分散度和历史出席/表决；
- 董事提名、实际当选、罢免和关键管理层任免；
- 预算、商业计划、融资、重大合同、资产处置和分红权限；
- 权利是实质性还是保护性，行使是否有现实障碍；
- 潜在表决权、期权、可转债及其可行使性；
- 代理人/实质代理关系和一致行动；
- 可变回报来源及买方影响回报的能力；
- 分步收购、一揽子交易、交割前后事实和购买日。

## 5. 董事会安排的常见误区

- “提名过半数”不等于候选人会当选；
- 独立董事须独立履职，不应直接视为收购人的受控席位；
- 原股东对预算、融资、核心业务或高管的否决权可能是实质性权利；
- 过渡期承诺和反垄断 standstill 会限制买方在交割前主导经营；
- 管理层留任、业务依赖和代理关系可能形成反证。

## 6. 购买日与时间线

把签约、协议生效、监管批准、股份过户/登记、董事当选、高管任免、账户/印章/系统权限和实际经营移交分别列日。并表起点取决于控制实际取得，不机械等于签约日、付款日或登记日。

## 7. 审计师确认包

提交给项目审计师：

- 交易步骤图和 fully diluted cap table；
- 交割前后章程、股东协议及保留事项；
- 董事/高管提名、任免和生效文件；
- 其他股东持股、分散度和历史投票资料；
- 预算/商业计划/融资/分红决策机制；
- 表决权委托、放弃、一致行动及退出安排；
- 过渡期和监管限制；
- 控制三要素备忘录、反证和购买日建议。

## 8. 输出规则

结论使用条件式：

> 该结构在【具体事实】成就且不存在【反证】的前提下，可支持管理层按准则评估取得控制；最终合并范围及购买日需由管理层与项目审计师基于交割时事实确认。

不得承诺“可以并表”。若并表是交易硬目标，可把审计师预沟通、治理文件定稿和交割事实证明纳入决策/交割材料，但审计师意见不能替代真实控制事实。
