# 并表证据检验与会计任务包接口

本模块只组织会计控制、合并范围和购买日判断所需事实，不替代管理层、审计机构或会计专家的结论。法律控制、经营者集中控制和会计控制分别分析。

## 前两维输入

| 前两维输入 | 最低证据 |
|---|---|
| 控制目标和口径 | 证券监管、治理、经营者集中、会计及外资/安全审查控制矩阵 |
| 交易步骤 | 各步骤持股、权益、表决权、治理、全面摊薄和经营主导权变化 |
| 权利生效 | 签署、效力、审批、过户/交付、董事当选、管理层及权限切换时间线 |
| 结构反证 | 其他股东权利、独立董事、代理关系、过渡期、TSA 和 standstill |
| 失败路径 | 单步失败后的剩余权利、治理状态、业务依赖和恢复安排 |

输入不完整时将第三维标记为 `pending-professional-confirmation` 或 `blocked`，并把缺口送入会计任务包。

## 股权或主体路径证据

围绕会计控制三要素组织：

1. 对被投资方相关活动的权力；
2. 因参与而享有的可变回报；
3. 运用权力影响回报金额的能力。

证据包括其他股东分散度和历史表决、董事实际当选和罢免、关键管理层任免、预算/商业计划/融资/重大交易/分红权限、实质性与保护性权利、潜在表决权、代理关系、过渡期和监管限制。持股或董事席位只是证据，不是结论。

## P-ASSET 分支：资产边界与经营主导权

不取得卖方主体股权时，检验买方何时能独立主导所购资产或业务的生产、采购、定价、客户履约、预算、人员和资本开支，并核对合同、许可、场地、员工、工艺、系统及 TSA 依赖是否实际转移。经营主导权不自动决定会计分类。

## P-ASSET 分支：资产收购或业务合并

不以合同名称预设结果，向管理层和项目会计师移交：

- 取得组合中的投入与实质性加工处理过程；
- 有组织员工、知识、经验、系统和流程；
- 产出或持续产出能力；
- 集中度测试的选择、计算和底层数据（如适用）；
- 同一控制下或非同一控制下的事实；
- 资产/负债边界、价款分配与 TSA；
- 确认日 / 购买日候选及各候选日完成证据。

资产收购、业务合并、确认、计量、商誉和列报均由管理层及项目会计师判断。

## 购买日与反证

分别记录签约、协议效力、监管决定、股份过户或资产交付、董事当选、高管任免、账户/印章/系统权限和实际经营移交。购买日不机械等于签约、付款、登记或交付日。

每条路径都输出：支持事实、反证、缺失证据、购买日候选和所需专业确认。如果推荐路径不能支持硬性并表目标，应改造、降级或排除路径，而不是把会计意见写成替代事实。

## 会计任务包接口

统一字段为：`Package ID｜接收方｜来源方案/维度｜目的｜待核事实/待完成动作｜输入材料｜问题或指令｜责任人｜期限/阶段｜完成证据｜结果回传字段｜状态`。

结果回传字段至少包括：三要素判断所依赖事实、反证是否关闭、购买日意见、仍需补充证据、对路径可行性/推荐/时间线的影响和专业确认状态。

条件式表达可以说明某结构事实“可支持管理层和项目会计师评估”；不得承诺可以并表或直接给出最终会计结论。
