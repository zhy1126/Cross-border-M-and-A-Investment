# 非上市公司股权结构规划（`P-EQUITY`）

本路由只规划非上市公司股权收购、控制型增资、老股与增资组合、分阶段交易及法定合并比较。纯新增少数融资且不追求控制、业务或资产的事项不在本路由内执行文件审阅。

## 结构目标

先明确拟取得的股权、表决权、董事会与关键经营权力、控制时点、并表要求、资金用途和卖方留存。Buyer 默认关注控制和执行确定性；切换 Seller 后重新评估条件可控性、价格确定性和改道边界。

事实允许时至少比较三个方案；不足三个时列明被排除路径及原因。

常见候选包括：

- 老股转让：主体与合同延续，但历史责任留在目标公司；
- 增资取得控制：资金进入公司，但需验证程序、稀释、用途和治理；
- 老股加增资：比较两条腿的依赖、同步交割和单腿失败；
- 分阶段收购：明确各阶段权力、定价、触发、long-stop 和第二阶段失败恢复；
- 法定合并：只作为需进一步核验程序、债权人、许可、税务和责任承继的候选路径。

## 关键约束与证据

每条路径至少记录：

| 类别 | 结构规划所需证据 |
|---|---|
| 权属与资本 | 章程、股东名册、出资链、质押冻结、优先权/同意权、全面摊薄表 |
| 控制与治理 | 表决权、董事实际当选、保留事项、管理层任免、其他股东权利和历史运行 |
| 步骤与资金 | 老股/增资价款流向、融资、付款、登记、治理与权限切换时点 |
| 外部约束 | 经营者集中、外资、国资、行业许可、安全审查和第三方同意触发事实 |
| 并表证据 | 相关活动、实质性权利、可变回报、反证和购买日候选 |

不能假设法定合并会使合同、许可、数据或债务无障碍承继。

## 分阶段与失败恢复

每阶段写明股权、表决权、董事席位、经营权限和控制状态。第二阶段须区分确定义务、期权或继续协商，并列明触发、定价、资金和最迟完成日。

第一阶段至第二阶段之间的价值保护不得构成提前控制。第二阶段失败时比较回购、退出、治理降级、价格调整、业务隔离和替代收购路径；把所需有限 CP、同步/交叉交割、long-stop 和失败后果移交交易文件任务包。

## 输出与交接

- 尽调任务包：只验证会改变路径、控制或推荐的股权、许可、同意和治理事实；
- 交易文件任务包：只移交步骤、条件、控制切换和失败恢复要求；
- 审批任务包：只移交影响路径和时点的程序；
- 会计任务包：只移交并表证据和购买日候选。

本路由不完成全面尽调、整套交易文件起草或审阅、全议题谈判、申报、交割管理、整合或索赔。
